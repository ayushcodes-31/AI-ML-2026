Stack → Linear data structure following LIFO
LIFO → Last In First Out
Push → Insert element into stack
Pop → Remove top element from stack
Peek → View top element without removing it
Queue → Linear data structure following FIFO
FIFO → First In First Out
Enqueue → Add element at the rear
Dequeue → Remove element from the front
List Comprehension → Short, concise way to create lists using loops
[x*x for x in range(5)]
Lambda Function → Anonymous one-line function
lambda x: x*x
deque → Double Ended Queue, supports insertion/deletion from both ends in O(1)
from collections import deque
Balanced Parentheses → Use a stack; push ( and pop for ); stack must be empty at the end.
Reverse String Using Stack → Push all characters, then pop them to get the reversed string.
